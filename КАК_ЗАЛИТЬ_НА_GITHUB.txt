КАК ЗАЛИТЬ ПРОЕКТ НА GITHUB
===========================

В этой папке уже всё готово: файлы разложены, git-репозиторий создан, коммиты сделаны.
Осталось только отправить их на GitHub. Есть два способа – выберите ОДИН.


СПОСОБ 1. ЧЕРЕЗ ТЕРМИНАЛ (рекомендуется, сохраняется история коммитов)
-----------------------------------------------------------------------

Шаг 1. Создайте пустой репозиторий на GitHub
  1) Зайдите на https://github.com и войдите в свой аккаунт.
  2) Справа вверху нажмите «+» → «New repository».
  3) Repository name: krugloe-schastie
  4) Выберите Public.
  5) НИЧЕГО больше не отмечайте (НЕ ставьте галочку «Add a README file»,
     НЕ выбирайте .gitignore и лицензию).
  6) Нажмите «Create repository». Страницу не закрывайте.

Шаг 2. Создайте токен (он нужен вместо пароля)
  1) Нажмите на свою аватарку справа вверху → Settings.
  2) В самом низу слева: Developer settings.
  3) Personal access tokens → Tokens (classic) → Generate new token → Generate new token (classic).
  4) Note: любое название, например «практика».
  5) Expiration: 30 days.
  6) Поставьте галочку «repo» (самая первая).
  7) Внизу нажмите «Generate token».
  8) СКОПИРУЙТЕ токен (начинается с ghp_...) и сохраните куда-нибудь.
     Второй раз GitHub его не покажет.

Шаг 3. Откройте терминал в папке проекта
  Распакуйте архив. Откройте папку krugloe-schastie, нажмите в пустом месте
  правой кнопкой → «Открыть в терминале».
  (Или в терминале: cd путь/к/krugloe-schastie)

  Проверьте, что вы в нужной папке – команда должна показать README.md:
      ls

Шаг 4. Если git ещё ни разу не настраивался, выполните (один раз на компьютере):
      git config --global user.name "Грищенко И.Г."
      git config --global user.email "ваша_почта_от_github"

Шаг 5. Привяжите папку к репозиторию (замените ЛОГИН на свой логин GitHub):
      git remote add origin https://github.com/ЛОГИН/krugloe-schastie.git

Шаг 6. Отправьте:
      git push -u origin main

  Спросит:
      Username: ваш логин GitHub
      Password: ВСТАВЬТЕ ТОКЕН из шага 2 (не пароль от GitHub!)
  При вставке токена символы не видны – это нормально, просто нажмите Enter.

Шаг 7. Обновите страницу репозитория на GitHub – там появятся все файлы и README.
  Скопируйте адрес страницы (https://github.com/ЛОГИН/krugloe-schastie) –
  его нужно вставить в отчёт, подраздел 11.1, вместо <логин>.


ЧАСТЫЕ ОШИБКИ
  «remote origin already exists»
      → git remote set-url origin https://github.com/ЛОГИН/krugloe-schastie.git
        и снова git push -u origin main
  «Authentication failed»
      → вместо пароля нужно вводить ТОКЕН (шаг 2). Проверьте, что у токена стоит галочка repo.
  «rejected ... fetch first»
      → при создании репозитория отметили README. Удалите репозиторий на GitHub
        (Settings → в самом низу Delete this repository) и создайте заново пустым (шаг 1).
  «git: command not found»
      → поставьте git: sudo apt install git   (или sudo dnf install git)


ЕСЛИ ПОТОМ ЧТО-ТО ИЗМЕНИЛИ (новый коммит)
      git add .
      git commit -m "Коротко что сделано, например: Исправить тест цены"
      git push


СПОСОБ 2. БЕЗ ТЕРМИНАЛА, ЧЕРЕЗ САЙТ (проще, но без истории коммитов)
--------------------------------------------------------------------
  1) Создайте репозиторий как в шаге 1, но можно сразу отметить «Add a README file».
  2) На странице репозитория: «Add file» → «Upload files».
  3) Откройте распакованную папку krugloe-schastie, выделите ВСЁ содержимое
     (src, tests, docs, README.md, .gitignore, этот файл) и перетащите в окно браузера.
     Папку .git перетаскивать НЕ нужно (она скрытая, её обычно и не видно).
  4) Внизу в «Commit changes» напишите: Конфигурация, тесты и документация
  5) Нажмите «Commit changes».
  Если сайт откажется грузить .gitignore (файл скрытый) – не страшно, без него всё работает.
