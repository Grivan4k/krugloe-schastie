# Круглое счастье — ИС учета сети ресторанов быстрого питания

Учебная практика ПМ.02 «Осуществление интеграции программных модулей».
Конфигурация для платформы **1С:Предприятие 8.5** (управляемое приложение, интерфейс «Такси»).

Автор: Грищенко И.Г., группа ИС(ТП)-41, ГБПОУ РХ «Хакасский политехнический колледж», 2026.

## Состав репозитория

| Каталог | Содержимое |
|---|---|
| `src/cf` | Конфигурация, выгруженная в XML-файлы (Configuration.xml и объекты) |
| `tests/features` | Сценарии Vanessa Automation ТН-01 – ТН-16: граничные значения полей |
| `tests/run_va.sh` | Скрипт запуска Vanessa Automation в Linux |
| `docs` | Отчет по практике, тестовая документация, тестовые наборы, словарь данных, ER-диаграмма |
| `docs/diagrams` | Диаграммы UML и ER-диаграмма в формате draw.io |

## Возможности

- справочники ресторанов, офисов и складов, сотрудников, клиентов и скидочных карт;
- меню с ценами, печать меню, рецептуры блюд;
- регистрация и закрытие заказов: контроль стола, автоматические даты, запрет изменения закрытого заказа;
- поступление продуктов, остатки, долги перед поставщиками;
- отчеты: продажи официантов, топ-10 клиентов и блюд, остатки продуктов;
- роли: Администратор, Менеджер ресторана, Повар, Обслуживающий персонал.

## Установка

1. Создать пустую информационную базу и открыть ее в конфигураторе.
2. «Конфигурация → Открыть конфигурацию», затем «Конфигурация → Загрузить конфигурацию из файлов…» и указать каталог `src/cf`.
3. Обновить конфигурацию базы данных (F7).
4. Запустить 1С:Предприятие: при первом запуске пустой базы создаются пользователи (пароль у всех `123`), программа перезапускается.
5. Войти под пользователем «Администратор» и выполнить «Предприятие → Заполнение тестовыми данными» (только для тестовой базы).

| Пользователь | Роль |
|---|---|
| Администратор (скрыт в списке выбора) | Администратор |
| Менеджер Ресторана | Менеджер ресторана |
| Повар | Повар |
| Обслуживающий персонал | Обслуживающий персонал |

## Резервное копирование

Основной способ — конфигуратор, «Администрирование → Выгрузить информационную базу…» (файл `.dt`).
Восстановление — «Администрирование → Загрузить информационную базу…». Подробно — раздел 9 отчета.

## Автоматизированное тестирование (Vanessa Automation)

Нужны платформа 8.5 и `vanessa-automation-single.epf` с https://github.com/Pr-Mex/vanessa-automation/releases.

Все сценарии выполняются под пользователем «Администратор» и проверяют поля на граничных значениях.
Перед прогоном база должна быть только что заполнена тестовыми данными: сценарии создают заказы, блюда, карты и клиентов. Удобно один раз выгрузить заполненную базу в `.dt` и восстанавливать ее перед каждым прогоном.

**Вручную.** Запустить базу с параметром `/TESTMANAGER` под пользователем «Администратор», открыть
`vanessa-automation-single.epf` («Файл → Открыть»), загрузить каталог `tests/features` и выполнить сценарии.

**Скриптом (Linux):**

```bash
cd tests
./run_va.sh ~/1c/КруглоеСчастье ~/va/vanessa-automation-single.epf        # открыть VA со сценариями
./run_va.sh ~/1c/КруглоеСчастье ~/va/vanessa-automation-single.epf auto   # выполнить все сценарии
```

Результаты прогона: `tests/out/log.txt` и `tests/out/status.txt` (0 — все сценарии пройдены).

| Файл | Поля | Наборы |
|---|---|---|
| `01_ЧисловыеПоляЗаказа.feature` | Стол (1 – 999), Количество (1 – 99 999) | ТН-01 – ТН-06 |
| `02_ЦенаБлюда.feature` | Цена блюда (0,01 – 99 999 999,99) | ТН-07 – ТН-11 |
| `03_ДатаИСтроки.feature` | Дата выдачи карты (не позже текущей), Фамилия и Имя клиента | ТН-12 – ТН-16 |
